📐 نظرية القيمة الوسطية (IVT)

If f is continuous on [a,b]
and W is between f(a) and f(b)
then ∃ c ∈ [a,b] such that f(c) = W
Special case (finding zeros):
If f(a)·f(b) < 0
then ∃ c ∈ (a,b) such that f(c) = 0
